## Unity conversion notes
- **Draco/KTX2**: use glTFast + com.unity.cloud.draco + com.unity.cloud.ktx. Our .quest/.opt-ktx2 GLBs keep float POSITION, skin weights and morphs (no KHR_mesh_quantization; patch_quant_fix existed because quantized POSITION broke loads). Prefer re-importing source GLBs and letting Unity compress if the importer struggles.
- **Quest 3 budgets**: 72 fps (13.9 ms), <=150 draw calls (world <=110), player LOD0 100-120k tris, NPC <=30k, textures <=256 MB GPU. LOD switch 10/25/50 m (perf/lod-budgets.md, .csv/.json per GLB).
- **Textures**: POT always (NPOT KTX2 -> BC7 mips not multiple of 4 -> black; Ikki NPC bug). In Unity use ASTC (6x6 color, 4x4/5x5 normals) on Android/Quest; color sRGB, ORM (R=AO G=rough B=metal) and normals linear, OpenGL +Y normals (Unity imports +Y fine). Caps: color 2048, normal/ORM 1024.
- **noNormal**: Caali G and crew NPCs ship without normal maps (glb_strip_normals.py) — measured negligible visual loss at Quest distance; Anika LOD1/2 normals dropped, LOD0 keeps 768 UASTC normals. Keep that in Unity LODGroups.
- **Rider style opt3** = stylized realistic PBR (not toon); gate in perf/render-style/rider_style_opt3_gate.py + perf/rider-style-opt3-gate.md. Map to URP Lit.
- **XR FX memory**: on Quest, no full-screen post bloom in XR. WebXR fix frees composer rt1/rt2+depth (~33 MB @1080p) on sessionstart. In URP: disable Bloom/post on the XR camera for Quest; fake glow with emissive + additive FX meshes.
- **FXBLOOM threshold**: setupFX bloom high-pass (Palma proposal, carried in patch_xr_fxmem.py) with luma clamp: only pixels above threshold bloom; day pbr sky cyan fix; known risk: pale emitters (white signs, lamp heads) lose bloom. Unity: Bloom threshold ~0.9-1.0 + clamp on desktop/flatscreen only.
- **Gamepad**: gamepad.js BUTTONS map follows the W3C standard mapping (0 A,1 B,2 X,3 Y,4 LB,5 RB,6 LT,7 RT,8 View,9 Menu,10 L3,11 R3,12-15 D-pad,16 Guide). Quest controllers: Meta button is reserved by the OS, so Menu (left) emulates Start/pause; Meta+Menu combo emulation is in gamepad.js. Remap: LB = L special, D-left grapple, boost L3. In Unity Input System: one Action Map with <Gamepad> and <XRController>{LeftHand}/{RightHand} bindings (primaryButton/secondaryButton/menu/trigger/grip); haptics via SendHapticImpulse (40 ms/hand rate limit, comfort scale).
- **Perf gate**: 72 fps sustained on Quest 3 (OVR Metrics), draws <=150, tex <=256 MB, 0 console errors, 0 404, colour match before/after shots; tests/drawcall_budget.py, tests/xr_fxmem.py, perf/drawcalls/dc_probe.js.
